# خدمات طلاب جابر بن حيان

موقع خدمات طلابية يعمل مع Firebase Authentication وCloud Firestore، ويحتوي على تسجيل الطلاب، الملف الشخصي والشعبة، الخدمات المدفوعة، السلة، التحويل البنكي، فتح واتساب لإرسال إيصال التحويل، الطلبات، ولوحة الإدارة.

## الأسعار الافتراضية
- إنشاء بحوث احترافية + QR: 9.99 ريال
- إنشاء مشاريع للمعلمين: 30 ريال
- حل واجبات: 15 ريال
- خدمة طلابية إضافية: 10 ريال
- اختبار محاكاة: 13.99 ريال
- مشروع تخرج بالكامل: 50 ريال

يمكن تغيير الأسعار أو حذف وإضافة الخدمات من لوحة الإدارة.

## 1) Firebase
1. أنشئ مشروعًا في Firebase Console.
2. أضف Web App.
3. انسخ إعدادات Web App إلى `firebase-config.js`.
4. فعّل Authentication > Email/Password.
5. أنشئ Firestore Database.
6. طبّق `firestore.rules` من Firebase Console أو عبر Firebase CLI.

## 2) إعداد التحويل وواتساب
افتح `firebase-config.js` وعدل:
- `whatsapp`: رقم واتساب بصيغة 9665xxxxxxxx بدون +.
- `bankName`: اسم البنك.
- `beneficiary`: اسم المستفيد.
- `iban`: الآيبان.

## 3) أول مدير
أنشئ حسابًا عاديًا من الموقع، ثم في Firestore افتح `users` ثم مستند UID الخاص بك، واجعل:
`role = admin`

بعد إعادة تسجيل الدخول ستظهر لوحة الإدارة.

## 4) التشغيل في VS Code
استخدم Live Server، أو:
```bash
python -m http.server 5500
```
ثم افتح `http://localhost:5500`.

## 5) الاستضافة
ثبّت Firebase CLI:
```bash
npm install -g firebase-tools
firebase login
```
ثم اربط المجلد بالمشروع:
```bash
firebase init hosting firestore
```
واجعل مجلد Hosting هو `.` ثم:
```bash
firebase deploy
```

## ملاحظة عن الدفع
هذه النسخة تستخدم التحويل البنكي اليدوي. لا يوجد تحقق آلي من التحويل: الطالب يحول ثم يرسل الإيصال عبر واتساب، وأنت تتحقق منه وتتواصل معه وتغيّر حالة الطلب من لوحة الإدارة.

## ملاحظة تعليمية
يمكنك تقديم الخدمات كمساعدة تعليمية ومراجعة وتجهيز منظم، مع الالتزام بسياسات المدرسة وعدم تقديم العمل على أنه عمل الطالب إذا كانت اللوائح تمنع ذلك.
